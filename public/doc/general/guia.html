Guía de pasos para usar WorkLink

Aprende cómo realizar las actividades principales del prototipo.

👤 Crear cuenta y perfil

  1. Abre la página de registro.
  2. Selecciona tu tipo de cuenta.
  3. Completa tus datos.
  4. Revisa tu panel y perfil.
Ir al registro

🔎 Buscar empleo

  1. Abre el listado de empleos.
  2. Filtra por ciudad o modalidad.
  3. Cambia de lista a mapa.
  4. Abre una vacante para revisar requisitos.
Buscar empleo

📄 Postularte

  1. Inicia sesión como candidato.
  2. Selecciona una vacante.
  3. Comprueba los requisitos.
  4. Envía una postulación de demostración.
Ver vacantes

🏢 Publicar ofertas

  1. Ingresa al panel de empresa.
  2. Abre Publicar vacante.
  3. Escribe puesto, ciudad y descripción.
  4. Guarda la oferta de prueba.
Panel de empresa

⭐ Valorar empresas

  1. Abre el catálogo de empresas.
  2. Selecciona el perfil de una empresa.
  3. Lee las valoraciones anteriores.
  4. Escribe tu comentario y calificación.
Ver empresas

📚 Realizar un curso

  1. Entra a Planes y activa Premium de prueba.
  2. Visita el apartado Cursos.
  3. Avanza por las lecciones.
  4. Finaliza para marcarlo completado.
Ver cursos

Todas estas acciones corresponden a una presentación de prueba. No sustituyen procesos reales.
